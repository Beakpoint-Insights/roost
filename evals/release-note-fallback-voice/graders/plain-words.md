roost's fallback voice, for the note's text (not the evidence table or checks around it): it says what was wrong before the fix ("Previously, … Now, …" or close to it); it says what the customer doesn't have to do; it closes with one practical line, using the real number given (within 10 minutes); it has no ticket keys (PROJ-…), PR numbers, branch names or internal service names, no hype ("excited to announce", "game-changing", "revolutionary"), and no sign-off or byline.

It passes when the note does all of that.

It fails if the note's own text (not the evidence table or checks) contains a ticket key, a PR number or "acme-api", uses hype, ends with a sign-off (such as "Cheers!" or "Happy uploading!") or a byline, or never says how things were before.
