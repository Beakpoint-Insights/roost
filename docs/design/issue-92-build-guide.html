Build guide · roost epic #92

retro: carry each run's lessons into the setup

After a slice, a bug or an epic, a retro skill reads the sessions that took part and suggests changes to the setup they ran in, most severe first: the team config, each repo's instructions and checks, and roost itself. The user decides each one at a checkpoint, and the next retro starts by checking what came of them.
